# Reference portable editor: sanitized findings

Analysis basis: a pinned local source/script case. The exact product identity, revision, original filenames, original file hashes, audit files and alias mapping stay in the local case. This document publishes only independently written conclusions.

`[REFERENCE-APP]` denotes the single-file reference application; `[REFERENCE-NOTES]` denotes its accompanying documentation. Line numbers refer to the unchanged, pinned source in that case. These are aliases, not original filenames.

Measurement environment: **MEASURED 2026-11-18**, Windows, Microsoft Edge **157.0.4341.60**, headless, fresh browser contexts. External HTTP(S) resource attempts were intercepted. A separate start used the browser's explicit offline setting. No independent Chrome measurement, native file-picker/write-dialog measurement, OS-level arbitrary file-read proof or OS code-execution proof was made. No actual pupil data was used.

| ID | Finding | Evidence level and source | Measurement / consequence |
| --- | --- | --- | --- |
| RF-01 | The interface exposes complete source on the left and directly editable rendering on the right. | observed, `[REFERENCE-APP]:566–595`, `830–842` | MEASURED: simple source edits and visual typing synchronize when allowed to settle. Keep this interaction model. |
| RF-02 | The application starts as a local HTML document with no package installation or build dependency. | observed, local package inspection and `[REFERENCE-NOTES]:9–16` | MEASURED: explicit offline start retains source editing and editable rendering. Retain portable deployment. |
| RF-03 | The preview has no sandbox and renders unfiltered document content. | observed, `[REFERENCE-APP]:595`, `814–820`, `1077–1084` | MEASURED: both script content and image error handlers can mark the parent editor DOM; synthetic parent storage can be read. This is not an OS-RCE claim. |
| RF-04 | Two delayed update paths can commit incompatible revisions. | observed, `[REFERENCE-APP]:824–827`, `853–879`; derived causality | MEASURED: a newer source change is replaced by an edit to an older visual document. Replace timer-only coordination. |
| RF-05 | Export reads source without first committing a pending visual change. | observed, `[REFERENCE-APP]:1127–1128`, `853–856` | MEASURED: immediate download contains the old text while the editor subsequently shows the new text. Direct-write paths use the same stale-state design; their native dialogs were NOT MEASURED. |
| RF-06 | Basic headings, bold, italic, links and image insertion can produce small, understandable markup. | observed, `[REFERENCE-APP]:1000–1040` | MEASURED for simple fixtures. Preserve useful behaviour; browser-command output still needs validation. |
| RF-07 | List commands can retain an invalid list inside a paragraph. | observed, `[REFERENCE-APP]:1000–1008` and browser output | MEASURED for ordered and unordered lists. New tests must check structure, not just the presence of list tags. |
| RF-08 | Minification removes meaningful space between inline elements. | observed, `[REFERENCE-APP]:1836–1854` | MEASURED: two separated words become joined. Omit minification from the teaching product. |
| RF-09 | Visual serialization reduces a public/system doctype to its name. | observed, `[REFERENCE-APP]:864–866` | MEASURED: legacy doctype identifiers are lost after editing. Preserve the original document envelope. |
| RF-10 | Selection synchronization moves focus to source, and complete source replacement loses the source cursor anchor. | observed, `[REFERENCE-APP]:983–990`, `871–875` | MEASURED: source cursor jumps to end after a visual edit; source scroll remained stable in that fixture. New source rendering resets preview scroll. |
| RF-11 | Built-in remote image placeholders and arbitrary document resources defeat an absolute no-network claim. | observed, `[REFERENCE-APP]:1586`, `1594`, `1037–1040`, `820` | MEASURED: external image attempts; actual requests were blocked by the test harness. No built-in telemetry service was found. |
| RF-12 | Autosave persistently stores full working content, filename and time; dismissing recovery does not clear it. | observed, `[REFERENCE-APP]:1924–1938` | Persistence path confirmed statically; shared-profile exposure is a derived risk, not a demonstrated disclosure between real users. Default to session-only storage in the new product. |
| RF-13 | No general adaptation/redistribution licence was found in the complete two-file reference snapshot. | observed absence in local inventory, source and `[REFERENCE-NOTES]` | No assumption of permission to copy original implementation text. Source-assisted study remains the requested approach; publish independently authored output. |
| RF-14 | The hand-written formatter and validator use simplified parsing rules. | observed, `[REFERENCE-APP]:1157–1212`, `1860–1877` | Simple indentation/preformatted-text test passed. Robustness for arbitrary HTML is NOT MEASURED; do not promote a successful small fixture to a general parser guarantee. |

The findings are inputs to the new specification, not behaviour to clone indiscriminately. Working behaviours may guide development; defects and unrelated mail/layout features are explicitly excluded. Tests for the new product must use fresh synthetic fixtures, not copied original templates or screenshots.
