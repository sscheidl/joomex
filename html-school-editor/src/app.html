Kurze Hilfe

  • Links steht der HTML-Code, rechts siehst du deine Seite. Du kannst auf beiden Seiten schreiben – die andere Seite ändert sich mit.
  • Klicke rechts in einen Text: Links wird der passende Code gelb markiert.
  • Für Überschriften, Listen, Links und Bilder: zuerst rechts den Cursor setzen oder Text markieren, dann den Knopf drücken.
  • Speichern nicht vergessen! Der Editor merkt sich nichts, wenn du das Fenster schließt.
  • Skripte und Bilder aus dem Internet zeigt der Editor nicht an. Im Code bleiben sie erhalten.
  • Tasten: Strg+S speichern · Strg+Z rückgängig · Strg+Y wiederholen · Strg+B fett · Strg+I kursiv
