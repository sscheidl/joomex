Lege das Bild zuerst in den Ordner deiner Seite. Im Code steht dann nur der Name der Bilddatei. Erlaubt sind PNG, JPG, GIF und WebP.

Kurze Hilfe

  • Links steht der HTML-Code, rechts siehst du deine Seite. Du kannst auf beiden Seiten schreiben – die andere Seite ändert sich mit.
  • Klicke rechts in einen Text: Links wird der passende Code gelb markiert.
  • Für Überschriften, Listen, Links und Bilder: zuerst rechts den Cursor setzen oder Text markieren, dann den Knopf drücken.
  • Speichern nicht vergessen! Der Editor merkt sich nichts. Speichern unter … legt eine neue Datei an.
  • Bilder: Lege das Bild in den Ordner deiner Seite. Im Code steht dann der Dateiname. Zum Ändern klickst du das Bild an und drückst „Bild“. Der Editor zeigt die Bilder nur, wenn deine Seite im selben Ordner liegt wie der Editor.
  • Skripte und Bilder aus dem Internet zeigt der Editor nicht an. Im Code bleiben sie erhalten. Ein Bild aus dem Internet lädst du herunter (denk an das Urheberrecht) und legst es in den Ordner deiner Seite.
  • Farbe färbt den markierten Text. Tabelle fügt eine Tabelle ein. Steht der Cursor in einer Tabelle, kannst du damit Zeilen und Spalten einfügen oder löschen. Mit der Tab-Taste springst du in die nächste Zelle.
  • Gespeicherte Seite ansehen zeigt deine gespeicherte Seite in einem neuen Tab. Dort kannst du deine Links ausprobieren. Deine Seite muss dafür im Ordner des Editors liegen.
  • Tasten: Strg+S speichern · Strg+Z rückgängig · Strg+Y wiederholen · Strg+B fett · Strg+I kursiv · Strg+U unterstrichen
